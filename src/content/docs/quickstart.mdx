This guide walks you through authenticating with the CSSL Raindrop API and fetching your first batch of weather station observations.

<Steps>
  <Step title="Obtain an API Key">
    Log in to **CSSL Weather Intelligence** at [weather.cssl.ca](https://weather.cssl.ca), open your account settings, and navigate to the **API Keys** tab. Generate a new API key with the `read:stations` and `read:observations` scopes.

    <Callout type="note" title="Environment Credentials">
      Store your key securely. For client applications, use `VITE_BACKEND_URL` and inject your token via the `Authorization: Bearer <TOKEN>` header.
    </Callout>
  </Step>

  <Step title="Query Available Stations">
    Retrieve active stations filtered by bounding box or network name:

    <CodeGroup>
      ```bash
      # Using curl
      curl -X GET "https://raindrop.cssl.ca/api/v1/stations?network=cssl-mesonet" \
        -H "Authorization: Bearer YOUR_API_KEY"
      ```

      ```typescript
      // Using TypeScript & fetch
      const response = await fetch('https://raindrop.cssl.ca/api/v1/stations?network=cssl-mesonet', {
        headers: {
          'Authorization': `Bearer ${process.env.CSSL_API_KEY}`,
          'Accept': 'application/json',
        },
      });

      const stations = await response.json();
      console.log(`Found ${stations.length} active stations.`);
      ```

      ```python
      # Using Python requests
      import requests
      import os

      url = "https://raindrop.cssl.ca/api/v1/stations"
      headers = {"Authorization": f"Bearer {os.environ['CSSL_API_KEY']}"}
      params = {"network": "cssl-mesonet"}

      res = requests.get(url, headers=headers, params=params)
      stations = res.json()
      print(f"Loaded {len(stations)} stations.")
      ```
    </CodeGroup>
  </Step>

  <Step title="Fetch Real-Time Observations">
    Once you have a `station_id`, query current weather conditions including 2m temperature, relative humidity, wind speed, gust, and barometric pressure:

    ```bash
    curl -X GET "https://raindrop.cssl.ca/api/v1/observations/latest?station_id=CA-ON-0492" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    The response returns structured JSON with ISO timestamps and calibrated units:

    ```json
    {
      "station_id": "CA-ON-0492",
      "timestamp": "2026-09-23T19:30:00Z",
      "temperature_c": 19.4,
      "dewpoint_c": 14.2,
      "relative_humidity": 72,
      "wind_speed_kmh": 24.5,
      "wind_gust_kmh": 41.2,
      "wind_direction_deg": 245,
      "pressure_kpa": 101.42,
      "precipitation_rate_mmh": 0.0,
      "quality_flag": "QC_PASSED"
    }
    ```
  </Step>
</Steps>
