The CSSL developer APIs allow authorized clients to access station catalog metadata, high-frequency time-series observations, and model grid parameters.

## Base URLs

| Service | Data Domain | Environment | Base URL |
| :--- | :--- | :--- | :--- |
| **Raindrop API** | Station Data & Observations | Production | `https://raindrop.cssl.ca/api/v1` |
| **Cyclone-serve** | Raster Data (Radar + Forecasts) | Production | `https://cyclone.cssl.ca/tiles/v1` |

## Authentication

All requests to the Raindrop API require a Bearer token in the `Authorization` header:

```http
GET /api/v1/stations HTTP/1.1
Host: raindrop.cssl.ca
Authorization: Bearer <YOUR_API_KEY>
Accept: application/json
```

<Callout type="note" title="Token Expiry & Scopes">
  API tokens are scoped to individual permissions (`read:stations`, `read:observations`, `read:models`). Tokens created through the dashboard default to a 1-year lifespan.
</Callout>

## Error Handling

Standard HTTP status codes are returned on failure along with a RFC 7807 problem details object:

<CodeGroup>
```json
{
  "type": "https://raindrop.cssl.ca/errors/unauthorized",
  "title": "Invalid or Expired API Key",
  "status": 401,
  "detail": "The provided Bearer token was either not recognized or has expired.",
  "instance": "/api/v1/stations?network=cssl-mesonet"
}
```
</CodeGroup>
