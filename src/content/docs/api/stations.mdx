### List Stations

`GET /api/v1/stations`

Returns a list of weather stations matching the specified filter criteria.

#### Query Parameters

<ParamField query="network" type="string">
  Filter stations by network code (e.g. `cssl-mesonet`, `eccc`, `noaa`, `on-mesonet`).
</ParamField>

<ParamField query="bbox" type="string">
  Bounding box coordinates specified as `min_lon,min_lat,max_lon,max_lat`.
  Example: `-83.5,41.5,-74.5,46.0` (Southern Ontario).
</ParamField>

<ParamField query="active_only" type="boolean" default="true">
  When set to `true`, only returns stations that reported valid observations within the last 15 minutes.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  Maximum number of stations to return per page (maximum 500).
</ParamField>

#### Response Fields

<ResponseField name="station_id" type="string" required>
  Unique alphanumeric identifier for the weather station (e.g. `CA-ON-0492`).
</ResponseField>

<ResponseField name="name" type="string" required>
  Official human-readable name of the station location.
</ResponseField>

<ResponseField name="latitude" type="float" required>
  Geographic latitude in decimal degrees (WGS84).
</ResponseField>

<ResponseField name="longitude" type="float" required>
  Geographic longitude in decimal degrees (WGS84).
</ResponseField>

<ResponseField name="elevation_m" type="float">
  Station elevation above mean sea level in meters.
</ResponseField>

<ResponseField name="capabilities" type="array<string>">
  Sensory instruments deployed at the station (e.g. `["temperature", "humidity", "sonic_anemometer", "barometer", "soil_moisture"]`).
</ResponseField>
